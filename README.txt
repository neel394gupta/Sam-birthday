SAMRIDHI — BIRTHDAY EXPERIENCE
===============================

Open index.html in a browser. No build step or server is required.

Personalization:
Edit SITE in js/script.js. The site is already personalized for Samridhi and Neel.

Music:
Put an MP3 in assets/audio/ and set SITE.music to its relative path, e.g.
SITE.music = './assets/audio/song.mp3'

The site is responsive, keyboard-accessible for the flip cards, and respects reduced-motion preferences.
